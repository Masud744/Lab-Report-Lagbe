Help & Documentation

Everything you need to generate clean, submission-ready academic programming reports.

How It Works

  1. Choose a template or start fresh from the Dashboard or Create Report page.
  2. Describe each lab task (or paste your own code from Code Workspace).
  3. Attach up to 4 screenshots per task for GUI/OpenGL/Web labs — arranged automatically in a crisp 2×2 LaTeX figure grid.
  4. Compile & export — the backend writes academic Methodology, Source Code, Execution Output, and Result & Discussion, then compiles with pdflatex.

Keyboard Shortcuts & Tips

  • Ctrl + K — Focus global search to jump to any report, template, or view.
  • Esc — Close PDF preview modal, search dropdown, or notifications.
  • Multi-Task Reports: Add multiple tasks in one form — sections automatically renumber to 1.1–1.5, 2.1–2.5.
  • Auto-Visualizations: OpenGL 3D Wireframe Cuboid and 2D DDA/Bresenham tasks automatically generate clean diagrams if you don't upload screenshots.
